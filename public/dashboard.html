Código Java DRM para tu Plugin

Pega este método en el `onEnable()` de tu plugin Java para validar la clave contra Synthetix en tiempo real:

public boolean verifyLicense(String key) {
    try {
        URL url = new URL("https://test.synthetixhost.lol/api/license/verify?key=" + key);
        HttpURLConnection con = (HttpURLConnection) url.openConnection();
        con.setRequestMethod("GET");
        con.setConnectTimeout(4000);
        return con.getResponseCode() == 200;
    } catch (Exception e) {
        return false;
    }
}
